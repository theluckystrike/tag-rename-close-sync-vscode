# Changelog

## 0.1.0

- First release: auto rename tag through VS Code's linked editing (one undo step), auto close tag on `>` and `</`, highlight matching tag, Go to Matching Tag, Select Tag Content and Rename Tag Pair.
- HTML, JSX/TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG and Markdown.
- Void tags and TypeScript generics are never closed; comments, strings, script and style bodies and template blocks are skipped.
- Files over 1 MB or 50,000 lines: live features off, with a status bar note.
