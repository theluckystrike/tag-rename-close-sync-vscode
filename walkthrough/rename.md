# Rename a tag

Put the cursor in a tag name and type. The matching tag changes with every key.

```html
<section class="card">   <- type here
  ...
</section>               <- changes with it
```

It is VS Code's own linked editing, so one Undo brings both tags back. There is no second edit that can break your undo stack.

Works in HTML, JSX and TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, ERB, Handlebars, XML, SVG and Markdown, also in new files that are not saved yet.
