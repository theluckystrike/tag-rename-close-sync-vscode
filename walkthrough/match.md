# See and jump to the matching tag

With the cursor on a tag, its partner gets a box in your theme's bracket colors, so you always see which tag a rename will change.

Right-click in the editor:

- Go to Matching Tag jumps between the open and the closing tag.
- Select Tag Content selects what is inside the element. Run it again for the whole element, then the parent.

The Tags item in the status bar shows what is on for the current file. Files over 1 MB or 50,000 lines get no live rename, so typing stays smooth; the status bar says so.
